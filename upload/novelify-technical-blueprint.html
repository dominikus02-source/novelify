01

What we're building

Product Overview

Novelify is a web-based SaaS platform that enables writers worldwide to craft novels using AI assistance, translate their manuscripts into English with literary quality, export to EPUB format, and publish to global platforms like Amazon KDP — all within a single workspace.

Core Value Proposition

Writers from non-English speaking countries face three major barriers to global publishing: the writing process itself, translation (cost + quality), and the technical complexity of publishing platforms. Novelify removes all three in one product.

Core Features — MVP
01
AI Writing Studio

Chapter-by-chapter AI writing assistant with plot consistency, character tracking, and writer's block breaker.

02
Literary Translation

AI translation that preserves voice, tone, and emotion — not word-for-word, but meaning-for-meaning.

03
EPUB Converter

One-click export to Amazon-ready EPUB with proper metadata, chapter structure, and formatting.

04
Synopsis Generator

AI-crafted back-cover blurb and Amazon product description optimized for discoverability.

05
KDP Launch Guide

Interactive step-by-step walkthrough for Amazon KDP setup: categories, keywords, pricing strategy.

06
Multi-Platform Export

Export formats for Google Play Books, Apple Books, Smashwords, and other global platforms.

What the user sees

Frontend

The frontend is a Next.js 14 application using the App Router pattern. It is fully server-rendered where possible, with client-side interactivity for the writing editor and real-time AI streaming responses.

Core Technologies

Framework Next.js 14 Core Full-stack React framework with App Router, SSR, and API routes built-in. Optimal for SEO and performance.
Language TypeScript Core Type safety across the entire codebase. Reduces bugs significantly for a solo developer.
Styling Tailwind CSS Core Utility-first CSS framework. Fast UI development with consistent design tokens.
UI Components Shadcn/UI Core Accessible, composable component library built on Radix UI. Installed per-component, not as a dependency.
Rich Text Editor TipTap Core Headless rich text editor built on ProseMirror. Powers the novel writing workspace with full formatting.
State Management Zustand Core Lightweight global state for project data, editor state, and user session.
Server State TanStack Query Core Data fetching, caching, and synchronization with the backend API.
AI Streaming Vercel AI SDK API Handles streaming AI responses in real-time, rendering text as it arrives from the Claude API.
Forms React Hook Form + Zod Util Form handling and validation throughout the platform.
Icons Lucide React Util Consistent icon set throughout the UI.

04

Server-side logic

Backend & API

The backend runs entirely within Next.js API Routes (Route Handlers), deployed on Vercel's serverless infrastructure. This eliminates the need for a separate Express or Fastify server, keeping the architecture lean for a solo developer.

API Endpoints
Endpoint Method Description
/api/write POST Streams AI writing assistance for a given chapter. Accepts: chapter context, plot outline, character profiles, user prompt.
/api/translate POST Translates a chapter or full manuscript from source language to English. Supports chunk-based processing for large texts.
/api/synopsis POST Generates Amazon-ready book description and back-cover blurb from manuscript summary.
/api/epub POST Triggers EPUB generation from finalized manuscript. Returns a signed URL to download the file.
/api/projects GET/POST CRUD for user writing projects. List, create, update, delete novel projects.
/api/chapters GET/POST/PATCH Chapter management within a project. Auto-save on 2-second idle.
/api/webhooks/gumroad POST Gumroad webhook to activate user accounts on purchase.
/api/webhooks/stripe POST Stripe webhook for subscription management (full launch).
Backend Utilities
ToolPackageUse
Rate Limiting Upstash Redis Infra Per-user rate limiting on AI endpoints to control API costs and prevent abuse.
Input Validation Zod Util Schema validation on all API request bodies.
Logging Vercel Analytics Infra Request logging and performance monitoring.
Email Resend Util Transactional emails: welcome, export ready, billing confirmation.

The brain of the platform

AI Layer

The AI layer is powered by Anthropic's Claude API. Claude is used for all natural language tasks: writing assistance, literary translation, synopsis generation, and chapter consistency checking. The Vercel AI SDK handles streaming responses to the frontend.

AI Stack
ComponentTechnologyDetails
Primary LLM Claude Sonnet (Anthropic) Core Main model for writing, translation, and synopsis. Best balance of quality and cost for literary tasks.
Streaming Vercel AI SDK Core useChat / useCompletion hooks stream tokens in real-time to the TipTap editor as the AI writes.
Context Management Custom prompt builder Core Builds rich system prompts per request including: novel genre, character profiles, plot outline, previous chapters, writing style guide.
Translation Quality Multi-pass prompting Strategy First pass: literal translation. Second pass: literary refinement. Ensures natural English prose, not machine translation feel.
Cost Control Token chunking Strategy Long manuscripts split into chapter-sized chunks (~4000 tokens). Prevents context overflow and controls API costs.

The output engine

EPUB Generation Engine

The EPUB engine converts the finalized, translated manuscript into a properly formatted EPUB 3.0 file ready for Amazon KDP, Google Play Books, Apple Books, and Smashwords. It runs as a Node.js process triggered by an API call.

EPUB Stack
ComponentTechnologyDetails
Primary Generator epub-gen (Node.js) Core Programmatic EPUB generation from HTML/CSS content. Handles chapter structure, metadata, and cover image injection.
Fallback / Quality Pandoc (CLI) Fallback Used for complex formatting needs. Pandoc converts structured markdown to EPUB with high fidelity.
Validation EPUBCheck (Java CLI) QA Validates generated EPUB against the EPUB 3.0 spec before delivery. Required for KDP compliance.
Cover Design Sharp (Node.js) Util Image processing for cover resize and format conversion to meet KDP requirements (2560x1600px minimum).
File Storage Supabase Storage Infra Generated EPUB files stored in Supabase bucket. Signed download URLs with 1-hour expiry.
EPUB Generation Flow
1
Collect Content

Fetch all translated chapters from DB. Validate completeness and chapter order.

2
Inject Metadata

Add title, author, language, ISBN (if available), cover image, and genre tags.

3
Generate EPUB

epub-gen compiles all chapters into structured EPUB 3.0 with table of contents.

4
Validate

EPUBCheck validates file. Errors returned to user with fix suggestions.

5
Upload & Deliver

File uploaded to Supabase Storage. Signed download URL sent to user via email + dashboard.

Data persistence

Database Design

Novelify uses Supabase (PostgreSQL) as the primary database. Supabase provides a managed Postgres instance with built-in Auth, realtime subscriptions, Row Level Security (RLS), and file storage — ideal for a solo developer.

Core Tables
-- Users
users
  id uuid PRIMARY KEY
  email text UNIQUE
  plan text DEFAULT 'free'       -- free | founding | pro
  word_count_used integer
  created_at timestamptz

-- Novel Projects
projects
  id uuid PRIMARY KEY
  user_id uuid REFERENCES users
  title text
  genre text
  source_language text           -- e.g. 'id', 'es', 'fr'
  target_language text DEFAULT 'en'
  status text                    -- draft | translating | ready | exported
  plot_outline text
  style_guide text
  created_at timestamptz

-- Characters
characters
  id uuid PRIMARY KEY
  project_id uuid REFERENCES projects
  name text
  description text
  role text                      -- protagonist | antagonist | supporting

-- Chapters
chapters
  id uuid PRIMARY KEY
  project_id uuid REFERENCES projects
  chapter_number integer
  title text
  content_original text          -- original language content
  content_translated text        -- English translation
  word_count integer
  status text                    -- draft | reviewed | locked
  updated_at timestamptz

-- EPUB Exports
exports
  id uuid PRIMARY KEY
  project_id uuid REFERENCES projects
  file_path text                 -- Supabase Storage path
  format text                    -- epub | pdf | mobi
  download_url text
  expires_at timestamptz
  created_at timestamptz

Solo Developer Notes

This stack is deliberately chosen for a solo developer: Next.js eliminates the need for a separate backend server, Supabase eliminates DevOps for the database, and Vercel eliminates deployment complexity. The entire stack can be bootstrapped in under a week and scaled to thousands of users without infrastructure changes.
